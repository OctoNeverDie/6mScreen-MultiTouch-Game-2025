## 프로젝트 의의

가로폭 6m 대형스크린에서 Multitouch를 활용하여 구동할 수 있는 새로운 게임 콘텐츠를 제시하고자 게임 Stellar를 고안 및 개발했습니다.

이 게임은 3인 이상의 멀티플레이어 협동 게임입니다. 1명이 지휘를, 나머지 사람들이 동작을 맡습니다.

지휘자 1명이 뒤에 서서 착시 이미지를 보고 형태를 설명하면, 앞에 선 나머지 사람들이 형태에 맞게 input을 넣습니다.

특정 동작에서 정지하고 3초간 홀드하면 한 개의 퍼즐이 클리어됩니다.

라이다 센서 기반 멀티터치를 잘 받아와서 속도감 있는 게임으로 제작하는 것이 관건이었습니다.

## 착시 원리
- 1. 배경화면 생성
    
    <aside>
    💡
    
    1. 전체 화면에 고주파 패턴이 있어야 한다.
    2. 고주파는, 밝기 채도 대비 전부 낮아야 한다. (앞사람 눈 고통 이슈)
    </aside>
    
    1. **무작위 컬러 노이즈 이미지 생성** (3840px x 2160px, 평균 128 회색, 분산 15)
    2. **전체 채도 낮춤** (BGR → HSV → BGR, 원래 채도의 20%)
    3. **전체 대비 낮춤** (중간값 128과의 거리를 0.5만큼 줄인다)
    ![background (1)](https://github.com/user-attachments/assets/491e416a-c4d1-45d7-9925-743ae55ddc1e)

    
 - 2. 별자리 상 생성
    
    Clip Studio로 수작업
    
    1. 3480px x 2160px
    2. 엣지로만 작업, 꼭짓점 잘 표현됐는지 확인 
    3. 이후 전체에 Gaussian Blur 100 적용
    ![croi2](https://github.com/user-attachments/assets/67f6367c-8d8b-44dd-a9f1-0aada081c3d4)


  - 3. 배경화면에 별자리 상 합침
    
    <aside>
    💡
    
    배경은 고주파로, 별자리는 저주파로 만든다.
    
    배경에 묻힌 저주파로 만들기 위해 밝기, 페더링, 알파값 조절
    
    </aside>
    
    1. 배경화면, 별자리 상 불러오기
    2. **상의 색을 배경의 평균색으로** 전부 바꾸기 (알파값 채널은 적용하지 않음, 고유의 알파값을 유지시킨다)
    3. **상의 밝기 더 어둡게 만들기**(dark-20)
    4. 상에 **가우시안 블러**를 이용해 그 테두리를 희미하게 만든다. (**페더링**)
    (테두리로 갈 수록 **alpha값 0**에 수렴 + **rgb는 해당 배경의 색평균값**에 수렴)
    5. **상의 알파값 높이기**(투명하게 만든다, *0.2)
    6. 이후 배경 위에 처리된 상을 합성
   ![croi2_4 178_9_2 804_2 416](https://github.com/user-attachments/assets/3cdfa1c7-53d2-4d1e-929b-7801f268739c)


  - 4. 최종 이미지 지표값 도출
    
    <aside>
    💡
    
    1. **배경화면과 별자리 상의 대비 차이**
    : 멀리서 봤을 때 얼마나 잘 보이는지 지표
    2. **75% 퍼센트 확대했을 때 색 분포**
    : 가까이서 봤을 때 얼마나 잘 안 보이는지 지표
        1. 색 분포가 제일 안 고른 값(색 분포 표준편차 최댓값)
        2. 색 분포의 평균(색 분포 표준편자 평균값)
        3. 색 분포 검사 횟수
    </aside>
    
    1. 배경화면과 상의 대비
    
    배경화면은 BGR로 저장,
    
    별자리 상은 BGRA로 저장된다.
    
    즉, Alpha가 0에 가까우냐 아니느냐로 배경화면과 상 분리 가능
    
    1. Gray Scale로 변환
    2. 알파값 기반 상 마스크, 배경 마스크 분리(alpha > 0.05시 상)
    3. 각 영역 평균 밝기 계산
    4. 대비 평균값 차이(절대값) 도출
    
    1. 색 분포 
    
    대부분의 상이 가운데에 맺혀으니 가운데만 검사한다.
    
    세로 가운데 80%, 가로 가운데 80% 범위에 한정하여 도출한다.
    
    예시 플로우 : 
    
    1. 가로 : 200, 세로 : 100일 때, 75퍼센트 확대해서 보면, 가로 : 50, 세로 : 25
    2. 세로의 양쪽 40% 버리고 세로 20 ~ 80 한정
    가로의 양쪽 40% 버리고 가로 40 ~ 160 한정
    3. 세로 20~45 가로 40~90에 위치하는 이미지의 색 분포를 검사
    4. 세로 20과 45의 중간값인 32.5~57.5 가로는 40~90의 중간값인 65~115 위치하는 이미지의 색분포를 검사
    5. 범위의 끝에 다다랐을 때는 끝 위치를 기준으로 한 번 더 검사 
    세로 55~80 가로 110~160에서 검사
    6. 이후 이 중 가장 색 분포가 고르지 않은 값을 도출
    7. 몇 번 색 분포도 검사했는지 횟수 도출
    8. 이때까지 검사한 색 분포도의 평균을 도출
